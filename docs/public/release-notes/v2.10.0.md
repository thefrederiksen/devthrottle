## v2.10.0 - September 24, 2026

What you send to an agent now arrives, whole and once - and the Director only tells you it was delivered
when the agent's own conversation record holds it. This holds on a machine with every core busy.

### Highlights
- Delivered means delivered: after every send, the Director looks for your text in the agent's own
  conversation record - Claude Code's transcript, Codex's rollout, Pi's session file, and the records of
  Grok, Copilot and OpenCode - instead of trusting what the terminal printed. If the text is not there, the
  send is reported as failed, never as done.
- Typed once, never doubled: when an agent was slow to show what was typed, the Director used to clear the
  input with Escape and type it again. Escape does not empty Claude Code's or Codex's input, so prompts
  arrived twice, run together. The Director now types once and, when a clear is needed, uses the key
  measured for each agent. It never sends again while the agent has shown nothing since the first send.
- Long texts go through a file: a text over 2,000 characters reaches Claude Code as a file reference it
  reads itself, and reaches Pi as a short line pointing at the file, the way long texts already reach Codex. With every core busy, an
  8,000-character paste into Claude Code was not taken in at all; through the file it arrives in seconds.
- A new Claude Code or Codex session's first prompt waits until the agent is proven to be reading input,
  instead of being typed into a screen that is still starting up.

### Also in this release
- Dictation keeps its dashes, curly quotes, accents, and pound and euro signs in Codex and Grok, which
  used to strip them.
- Enter is pressed again only when the screen shows your text still waiting and nothing running - no more
  stray Enters turning into blank lines in the next prompt.
- If you type into a session while the Director is sending to it, the Director no longer presses Enter or
  sends again on top of you, and two sends to the same session wait for each other.
- Long Codex prompts no longer end with a leftover instruction to "reply with the requested strings only".
- The Wingman no longer narrates a stop twice when a session's "carrying on" clock runs out, and a session
  that reported its work finished is never read as still carrying on.
- The Wingman pauses its retries while its model is not answering, and resumes once the model is back.

### Already in v2.9.2
v2.9.2 also carried these, which its notes did not list: cc-gmail answers in JSON (`--json` on `search`,
`list`, `read`, `draft` and `reply`, with the Gmail thread id on every answer); a session started in a
worktree counts as a session in its repository, so the repository list no longer grows with every
worktree; the Cockpit's session view opens on Chat with a single composer and one density switch; the
Cockpit uses less network; the Fleet Map shows a session on its own machine; and the macOS installer no
longer needs Xcode.
