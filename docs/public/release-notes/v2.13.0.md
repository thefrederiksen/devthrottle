## v2.13.0 - October 1, 2026

A Windows machine can now be installed and connected from the command line, with one sign-in in the browser.
And for accounts with turn judging on, a stopped session is red unless sessions under it are still working.

### Highlights
- `enroll` connects the Director it installed: after `devthrottle-setup-cli-win-x64.exe install` and
  `enroll --hosted` (or `enroll --gateway <url>`), you sign in once in the browser and the Director on that
  machine starts connected, as one device. Before, enroll saved the connection where the Director never
  looked, so the Director started with "No Gateway", and connecting again from the app added a second device
  for the same machine.
- One calm colour, and red when nothing is running under a stop. For accounts that have switched turn judging
  on (it is off by default) and for voice sessions: the Wingman reads a stopped session as cyan only while
  sessions under it are still working. A stop with nothing working under it is red, whatever wake-up it set
  itself, and a session read as cyan is read again the moment the last session under it stops. When the
  sessions under a stop are not known, the Wingman decides as before. Purple is gone; a calm row's words say
  whether it is done or carrying on.
- Voice mode switches itself off: when you answer five stops in a row without playing their narration, voice
  mode goes off for your account, exactly as if you had pressed the voice switch for all sessions. The phone
  and the Cockpit show a line saying when and why, and switching voice back on for all sessions clears it.
- The Wingman names a session you did not name, from your first prompt, the moment you send it: for accounts
  with turn judging on, a Claude Code session you started yourself. A name you give is never touched.

### Also in this release
- The narration call runs only for voice sessions, or when you ask, so a row's colour no longer waits for it.
- The carrying-on clock is removed: a calm row is no longer turned red after ten minutes.
- A prompt whose delivery the Director could not confirm is never offered "Send anyway", so it cannot be
  typed twice. A send cut off by a Director that stopped is settled as unconfirmed at start-up instead of
  staying "delivering" forever.
- A background agent can no longer take over its session's conversation pointer, which had frozen a session
  so that every dictation was refused. A Claude Code session with a name on its composer line can be sent to
  and rung again, and a desktop Send that is refused puts your words back in the box and says "Prompt not
  sent" instead of failing with an error.
- On the phone, the strip for a dictation more than 5 minutes old no longer grows past the screen with a long
  dictation; its quote scrolls inside it.
- Factory memory: a session that belongs to a factory starts with its factory's notes in its own folder, and
  can read and write them from the command line. The factory page in the Cockpit has a Memory tab to read,
  correct and restore them, and the Cockpit's New Session dialog can put a session in a factory.

The colour, naming, voice, narration, phone and Cockpit changes are in the hosted Gateway and are already live
there. The download carries the enroll fix, the Director side of the delivery fixes, the background agent and
composer fixes, and the factory notes folder.
