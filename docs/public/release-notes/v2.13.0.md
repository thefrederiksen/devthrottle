## v2.13.0 - October 1, 2026

A Windows machine can now be installed and connected entirely from the command line, and a stopped
session is red unless sessions under it are still working.

### Highlights
- `enroll` connects the Director it installed: after `devthrottle-setup-cli-win-x64.exe install` and
  `enroll --hosted` (or `enroll --gateway <url>`), the Director on that machine starts connected, as one
  device. Before, enroll saved the connection where the Director never looked, so the Director started with
  "No Gateway", and connecting again from the app added a second device for the same machine.
- One calm colour, and red when nothing is running under a stop: a stopped session is cyan only while
  sessions under it are still working. A stop with nothing working under it is red, whatever wake-up it set
  itself, and a session that was cyan is read again the moment the last session under it stops. Purple is
  gone; a calm row's words say whether it is done or carrying on.
- Voice mode switches itself off: when you answer five stops in a row without playing their narration, voice
  mode goes off for your account, exactly as if you had pressed the switch. The phone and the Cockpit show a
  line saying when and why, and switching voice back on clears it.
- The Wingman names a session you did not name, from your first prompt, the moment you send it. A name you
  give is never touched.

### Also in this release
- The narration call runs only for voice sessions, or when you ask, so a row's colour no longer waits for it.
- The carrying-on clock is removed: a calm row is no longer turned red after ten minutes.
- A prompt whose delivery the Director could not confirm is never offered "Send anyway", so it cannot be
  typed twice. A send cut off by a Director that stopped is settled as unconfirmed at start-up instead of
  staying "delivering" forever.
- A background agent can no longer take over its session's conversation pointer, which had frozen a session
  so that every dictation was refused.
- On the phone, the strip for a dictation more than 5 minutes old no longer grows past the screen with a long
  dictation; its quote scrolls inside it.
- Factory memory: a session that belongs to a factory starts with its factory's notes in its own folder, can
  read and write them from the command line, and the factory page has a Memory tab to read, correct and
  restore them. A session can be put in a factory from the New Session dialog.
