## v2.31.1 - October 25, 2026

A fresh install on Windows now finishes cleanly, instead of ending on "Setup finished with problems".

### Highlights
- A clean Windows install ends on a clean Complete screen: the v2.31.0 installer told a brand-new user "Tools did not install - please report this" (Archive asset requires extraction), even though nothing was wrong. The installer places the Director and the launcher, and the Director sets up the command line tools the first time it opens, as it always has. The installer no longer reports that as a failure.
