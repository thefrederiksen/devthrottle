## v2.40.0 - November 8, 2026

Disk space joins CPU and memory on the resource meter, and agents get email and calendar tools for any provider, plus a Mail Desk page that shows who checks each mailbox.

### Highlights
- Disk space on the resource meter: a DISK bar sits next to CPU and MEM on the Director, always shown. It fills with how full your tightest fixed drive is and names the free space left on it ("C: 6 GB"). It turns amber under 25 GB free and red under 10 GB, on any drive. Hovering lists every drive and how fast it is filling. A drive that cannot be read says so with the reason; it is never shown as empty. The same figures go up in the five-minute machine summary, the Cockpit machine page shows each drive's free space and recent history, and you get one inbox message when a drive goes red (at most once a day per drive) and one when it recovers.
- Email for agents, any provider: `dt-email` reads, searches and sends mail over standard IMAP and SMTP. In test mode it refuses every recipient outside the allowed test addresses, so a test can never mail someone by mistake. Credentials come only from cc-secrets.
- Calendar for agents, any provider: `dt-calendar` lists, creates and answers invitations over standard CalDAV.
- The Mail Desk page: one page that shows, for each mailbox, which machine checks it, where its sign-in is held and how the check works. `cc-devthrottle maildesk providers` lists what each provider supports, and a mailbox can now be read over IMAP with `dt-email`.
- An agent uses Your inbox like email: list, read, archive, restore, mark and reply from the command line, and leave a message in a factory's inbox.

### Also in this release
- The last system alerts that still went out by email now reach you in Your inbox with a push notification instead.
- An agent's message to a factory's inbox is refused for an account that has factories turned off, like every other factory route.
