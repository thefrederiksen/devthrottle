## v2.34.0 - November 3, 2026

Every DevThrottle release now lives in full on our own download server, ready for downloads and updates to move off GitHub.

### Highlights
- Every release on our own download server: each release now copies every file it ships - the Director, the launcher, the Gateway, the Cockpit, the mobile app, the setup wizard and command line, ffmpeg, Python and the tools - to devthrottle.com, in a folder of its own for each version. Each file is downloaded back and checked against the release's fingerprints before the release is published, and a release that cannot reach the download server is stopped rather than published without it.
- One address for downloads: devthrottle.com/download/files now serves those files. The Download button on devthrottle.com works exactly as before.

### Also in this release
- Nothing changes on your machine yet. Updates still come the way they always have; a later release switches every part of DevThrottle to update from devthrottle.com.
