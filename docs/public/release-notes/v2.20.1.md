## v2.20.1 - October 14, 2026

A fix release: License Switching reports its Claude accounts again, and a tools update can no longer
leave a machine without its tools.

### Highlights
- License Switching reports its accounts: a Director with the license switching setting on now reads
  the machine's real Claude login, so its Claude accounts and their usage reach the Licenses page.
  Before this fix the license tool refused the real login on every machine and the page stayed empty.
  Only the Director's own runs of the license tool may open the real login; sessions never inherit that
  permission, and a license command typed by hand is still refused. The setting stays off unless it is
  turned on.
- A tools update never leaves a machine with no tools: the hourly tools update used to delete the
  command line tools in place and then stop on a file a running tool held open, leaving every session on
  the machine without them. Now it first checks the tools can be replaced; if one is in use it changes
  nothing and tries again in 10 minutes. The old tools are set aside rather than deleted, and any failure
  puts them back.

### Also in this release
- One test that failed on correct code in the v2.20.0 release gate was removed.
