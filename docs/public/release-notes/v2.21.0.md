## v2.21.0 - October 15, 2026

Your Throttle gains a Systems tab that shows how your turns split across Windows, Linux and Mac, the Cockpit can filter its sessions by repository and machine with saved filters, and a factory can now be defined by one versioned definition kept on the Gateway.

### Highlights
- A Systems tab on Your Throttle. Beside Agents, the new Systems tab shows how your counted turns, sessions and
  agent-driven turns split across Windows, Linux and Mac, with each machine listed under its system. Each Director
  now reports its operating system when it connects, and every session records it. A machine whose system is not
  yet known is shown as Unknown rather than guessed, so the rows always add up to the Turns counted card. Once a
  machine runs this release its earlier sessions in the window take its system too, so the whole thirty days fill
  in after one update.
- Filter the Cockpit's sessions. A Filter button on the Sessions header narrows the list by repository and
  machine, with counts for each. A filter can be saved with a name and a colour and applied in one click, on the
  desktop and on the phone. The filter is kept in the page address, so each browser tab can show its own view and
  a link carries it.
- A factory defined by one definition. Where the factory area is turned on, a factory can be described by one
  definition - its settings, its seats, their briefs and how each starts - kept on the Gateway with every version.
  It can be read, saved as a draft, compared, published and brought back with
  `cc-devthrottle factory definition get`, `history`, `save`, `diff`, `publish` and `restore`. Every save is checked
  first and refused with each finding by file and line. Only a person publishes, and a publish updates the
  factory's registry entry, schedules and triggers together in one step, or changes nothing. Once a factory has a
  published definition, the other ways of changing it are refused with a message pointing at the definition;
  pausing, resuming and running its schedules still work. A definition can be exported as a folder of files and
  imported as a new draft with `cc-devthrottle factory export` and `factory import`.

### Also in this release
- A factory's records - its journals, working documents and attachments - can be kept on the Gateway instead of on
  one machine, with `cc-devthrottle factory journal`, `factory doc` and `factory attach`, and moved there once with
  `cc-devthrottle factory records upload`, which never deletes anything locally.
- Pausing or resuming a schedule from the Cockpit no longer switches that schedule's sessions to closing
  themselves.
- Saving a Cockpit session filter no longer fails with "Unexpected end of JSON input".

The Systems tab and the operating system on each session, the session filters, factory definitions and factory
records are in the hosted Gateway already. The download carries the Director's report of its operating system,
which is what moves each machine out of Unknown, and the new `cc-devthrottle factory` commands.
