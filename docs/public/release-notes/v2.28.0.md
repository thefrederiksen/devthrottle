## v2.28.0 - October 21, 2026

See which sessions are using up a Claude license, and plan what to stop so it lasts until the next one is free.

### Highlights
- What is using the license: the Licenses page in the Cockpit has a new What is using it tab, and the command line has `cc-devthrottle license sessions`. Both show, for every session, how much of the account's weekly limit it is using right now, over the last four hours and so far, grouped by session, by the session that started it, or by Mission.
- Make it last: pick a time - the moment another account has room again, this account's weekly reset, or any time you choose - and DevThrottle tells you whether the license will last until then, how fast it may be used to get there, and which sessions to stop if it will not. Tick sessions on the tab, or use `cc-devthrottle license plan --stop`, to see what stopping them would change. It only suggests; nothing is ever stopped for you.
- No paid plan: an account whose Claude plan has lapsed now says "No paid plan - renew it on claude.ai" instead of reading as out of date and asking you to sign in again, which could never help. DevThrottle will not switch a machine to such an account.

### Also in this release
- The weekly forecast now works from this week's average use, so it no longer says the weekly limit will not run out while the average says it will, and it keeps its history through a Gateway restart.
- The Fleet Manager knows how to answer "what should we cut to make this license last", and brings its suggestion to you as a decision rather than acting on it.
- Buttons in the desktop app have their label centred, and a blue button stays blue under the pointer instead of turning grey.
- On the What is using it tab you can enter what an account's plan costs a month, and the tab then shows each session's use in dollars.
