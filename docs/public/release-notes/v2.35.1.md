## v2.35.1 - November 5, 2026

Any of your machines can now switch to any of your Claude accounts, and the Mac Director no longer crashes when it starts a background command.

### Highlights
- Any machine can use any of your accounts: every machine now offers its browser profiles to help sign other machines in to your Claude accounts. Before, this was off unless you turned it on by hand, so a machine could only switch between the accounts it was already signed in to. When the Director starts, and once a day after that, it checks each browser profile on the machine to see which claude.ai account it is signed in to. That can briefly start a stopped browser or open a claude.ai tab in a running one. To turn it off on a machine, set `"offerApprovers": false` under `licenseSwitching` in that machine's config.json.
- The Mac Director no longer crashes when it runs a command: macOS could stop the Director, and every session in it, while it started a background command such as a git read. The Director now starts commands in a way that cannot trigger that crash.

### Also in this release
- The Licenses page no longer shows an account as not known when Claude reports only a weekly limit and no 5-hour window.
- The Licenses page no longer reports a license problem for a machine whose spare account has room again before its current account is expected to run out.
- When every worktree slot for a repository is in use, a new session is refused straight away with the reason, instead of after a long wait.
- The help assistant and the public documentation describe DevThrottle correctly.
- An install into a folder of its own with `--root` no longer changes the machine's Start Menu shortcut, PATH or app menu.
