# DevThrottle v2.4.0

The session list now tells you what every colour means, and the Wingman can tell a stop that needs you from one
that is only reporting - as an opt-in setting, off by default.

## What do the colours mean?

The session list in the Cockpit and on the phone has a new "What do the colours mean?" link. It opens a short
legend: every colour a session can show, what the session is doing, and whether it is asking for you. The words
come from the Gateway, next to the rules that decide the colours, so the legend and the dots always agree. If
you ever see magenta, the legend says what that means too: the screen received a colour it does not understand,
usually because the Gateway and the app are on different versions.

## The Wingman says whether a stop needs you (opt-in, off by default)

When a session stops, the Wingman can now read the screen and decide whether the stop needs you. This is an
account setting and it is off unless you turn it on. With it on:

- A stop that only reports finished work shows **cyan**, labelled "Done" or "Report", and is no longer counted as
  needing you. It stays in view, below the sessions that do need you.
- A session that said it will carry on by itself shows **purple**, "Carrying on". If it has not continued when it
  said it would, it turns red and says so.
- While the Wingman is still reading a stop, the row is yellow.
- In the Cockpit, a judged stop shows its options as buttons, so you can answer it without typing, and a
  "This is wrong" action records a verdict you disagree with.
- A snooze that ends with nothing new comes back calm instead of red, and a question that was still waiting is
  still shown as a question.

Brand-new sessions stay **green**, labelled "Ready", so a finished session never looks like a new one.

## The launcher updates itself on Mac and Linux

Until now only Windows launchers updated themselves. A Mac or Linux machine kept whatever launcher its installer
left behind while its Director moved on. From this release the launcher updates itself on every platform.

## Also in this release

- Voice mode names the right session when it speaks.
- When voice mode gives up on a spoken summary, the session no longer stays yellow: it asks for you instead.
- On Mac and Linux, `cc-devthrottle setup` looks for its commands in the right folder, so a healthy install no
  longer reports itself as broken, and it downloads the setup tool built for that machine rather than the
  Windows one.
- The phone's Chat tab has its full screen back. The Wingman's verdict panel is no longer shown there; answering a
  judged stop from its options is done from the Cockpit.
- The Director's session list shows the new cyan. A Director older than this release shows finished sessions in
  magenta until it updates.
