## v2.9.2 - September 22, 2026

The Director stays responsive through a long working day. Clicking a session no longer freezes the
window, and the storm of git work that followed every change in a repository is over.

### Highlights
- Clicking a session no longer freezes the window: switching to a session replays its terminal off the
  screen's thread, so the window keeps answering while a long scrollback is drawn. Coming back to the
  Terminal tab replays nothing at all unless the window changed size in between.
- The git storm is over: the repository watcher now waits for a repository to settle - 20 seconds of
  quiet, and never more than 60 - before it looks again, and a burst of changes to one repository becomes
  one follow-up check instead of one per change. A worktree whose commit and origin/main have not moved
  reuses the merge answer it already has instead of asking git again.
- The Director stays light as the day goes on: a burst of terminal output is handed to every reader as
  one shared copy instead of one copy each, and anything that only needs the end of a terminal - the
  doorbell, the screen checks - reads just the end instead of the whole buffer.

### Also in this release
- The session rail builds what it sends about each session once per change, instead of once for every
  place that asked.
- The window no longer reads files on its own thread, and one handler listens for changes to the session
  list instead of several.
- The doorbell takes a single look at a screen it cannot read, instead of two looks with a pause between
  them. More than half of all rings on a busy Director were of this kind.
- Device keys that the old "trial ended means cut off" rule had cancelled are given back.
- The guidance on who reviews a change now names Codex first, with Pi as the reviewer when Codex cannot.

v2.9.1 carried the first part of this work - the rate-limited terminal check, the cached browser
detection, the terminal drawing whole runs of text, the link cache and the calmer session rail. This
release finishes it.
