## v2.39.0 - November 8, 2026

The yellow license bar is gone everywhere - a small triangle with a count takes its place - a Director update now brings its command-line tools with it, a slow Director no longer sends a false "Schedule failed", and the Mission button always says Mission.

### Highlights
- The license bar becomes a triangle: the full-width yellow license strip is gone from the Director, the Cockpit and the phone. A small triangle with the number of problems sits beside the resource meter on the Director and beside the bell on the Cockpit and the phone - yellow for a warning, red when critical. Hovering lists each problem word for word, and a click opens Licenses.
- A Director update brings its tools along: before the launcher swaps an idle Director in, it installs that release's own cc-* tools. If it cannot - the tools are in use, the bundle is missing, the install fails - the update is held with the reason on the Director's update panel and the Gateway machine view, and the next pass tries again. Updating the Director had been leaving the tools a version behind, so a factory Secretary could start with instructions using a command its machine did not have, and the owner's message went nowhere.
- A seat that needs a command the machine's tools lack is not started: the factory inbox seats declare the commands they need, the Director asks its own installed tools for each one before starting the seat, and refuses with the missing command named.
- A slow Director is not a failed schedule: "Schedule failed" used to be sent whenever the Director took longer than 30 seconds to answer, even though the run started and reported fine minutes later. Now a failure is told only when the run did not start. And when a failure was told and the schedule then succeeds, you are told it recovered - once, respecting the schedule's Notify setting.
- The Mission button always says "Mission": with a document icon when the Mission has a document (click to open it), an outline when it has none, and a yellow circle with an exclamation mark when the session has no Mission. Hover or long-press shows the Mission's name and goal. The same on the Director, the Cockpit and the mobile app, ruled once by the Gateway.
- Clear a stuck factory inbox alert yourself: a "factory inbox is stuck" alert now has a "Dealt with it" control on the Cockpit and the phone. It clears exactly the messages the alert counted and records that you dealt with them; a message that gets stuck later raises a new alert.

### Also in this release
- The phone session header fits on one row: Back, Mission, the license triangle, the bell and the menu, on screens 360 pixels wide and up. The Voice mode tab is now called Voice.
- A report link opened on a phone reads at full width, and the Cockpit report page stacks in a narrow window.
- Reloading a Missions page in the browser shows the Fleet Map instead of raw data.
- The Cockpit's session rail is a little wider, so session names fit.
- The Director's colours can no longer fail when a screen is first built off the user-interface thread.
