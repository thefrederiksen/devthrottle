# DevThrottle v2.1.2

A release about sessions you are not watching: the ones nobody is holding, the ones that finish and
never say so, and the one you are trying to stop.

## Stopping a session asks you once, and takes your word for it

Stopping a session in the Director or the Cockpit had turned into an interrogation. Four sentences
explaining the audit trail, a box demanding a written reason, a Stop button that stayed switched off
until you filled it in, and then a panel that stayed open afterwards reporting what had happened to a
session you had just watched disappear from the list.

That reason requirement is real, and it stays where it belongs. It exists because one agent can stop
another agent's session, and when that happens the trail has to say why. It was never meant for you
stopping your own work: clicking Stop in your own window is as much authorisation as there is.

So both windows now ask one question - "Stop Deploy Manager?" - with Cancel, Stop, and a note you can
leave blank. The button works the moment the window opens. If you write nothing, the stop is recorded
as coming from you, from whichever screen you were on, so the trail is still complete. If the stop
works, the window simply closes and the session is gone. Only a failure says anything, and it says it
where you are looking, with your note still in the box so you can try again with one click.

The phone was fixed this way two days ago. All three screens now behave the same.

## A session stays quiet only while somebody is actually holding it

Whether a session could go quiet used to be decided by what kind of session it was - the seat it held
and how it was created, both fixed when it was born. So sessions were quietened for the category they
belonged to rather than because anyone was there to catch them. On 13 September six sessions sat grey
and labelled "Snoozed" with nothing snoozed, and five of the six had nobody who would ever come back
for them.

The question asked now is a live one, asked fresh every time: is there a supervisor alive right now?
If not, the session turns red and asks you, whatever kind of session it is. If so, it stays quiet and
belongs to that supervisor.

Alongside it, owning a session is now something a session has to say out loud. A session that spawned
another one used to take ownership of it silently, just because it could - the one way work stopped
being yours without anyone choosing it. A session spawning another must now declare who owns the
result. You spawning one, or a schedule firing, declares nothing, because there is nobody else it
could belong to.

Every session has exactly one owner, and it is either another session or you.

## A session tells its parent when the work comes back

Going quiet is only safe if somebody is told when it is over. Until now nothing was: a session finished
delegated work and simply stopped, so "quiet" could quietly mean "lost".

A session that was given work now reports back in its own words when it is done, and that report
interrupts its parent - which is the right cost, because a session that took ownership took on being
interrupted when the work returns. The old signal was a flag the parent had to think to go and look
at, and a signal nobody is obliged to read is not a signal.

With no live parent it sends nothing, because no parent means you, and a session you own is already
red and in your queue.

## A dictation to a session that has exited stops retrying forever

A dictation aimed at a session whose agent had already exited was refused and left unresolved, so the
phone kept trying it every few seconds - paying for a full transcript each time and throwing it away,
repainting a dead session orange on every lap. The only way to stop it was to delete the session.

It now resolves the first time, tells you the session has gone, and keeps your audio.

## Also in this release

- The Gateway's own unit tests had quietly grown past the time limit on the everyday test run, which
  meant they were being stopped before they finished and counted for nothing. They now run on the
  release check instead, where they count.
