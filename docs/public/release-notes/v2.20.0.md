## v2.20.0 - October 14, 2026

The hosted Gateway now asks for a plan for remote access from the Cockpit and the phone while the Director stays free, the Licenses page can switch, renew and add Claude accounts as well as show them, every factory seat gets a page of its own with a brief kept on the Gateway, and the Linux Director shows its icon in the app menu.

### Highlights
- Remote access needs a plan on the hosted Gateway. On the Free plan the Director keeps working and keeps connecting
  to the hosted Gateway; signing in to the Cockpit and enrolling or using the phone app now need the Remote plan, Pro,
  a team plan or a legacy hosted plan. A refused request shows one "Remote plan needed" notice, refuses only that
  request, and revokes nothing. New accounts are no longer given a trial; a trial already running is still honoured,
  and accounts that used the hosted Gateway before October 13, 2026 keep remote access for now. The hosted Gateway
  also checks each account's plan before every AI call it makes - dictation, text to speech, the Wingman, narration
  and the Mentor. A self-hosted Gateway is unchanged.
- The Licenses page acts, not only shows. Where license switching is turned on (it is still off by default, set
  `licenseSwitching.enabled` in a Director's config.json), the Licenses page in the Cockpit can now move every
  machine on one Claude account to another with Switch now, set the date a subscription renews, show when a machine
  could not renew its sign-in, set which machine approves each account's sign-ins, add a spare account and renew a
  sign-in. Nothing is sent before you confirm, and a refusal is shown in the Gateway's own words. The owner is
  emailed once when a sign-in about to end cannot be renewed.
- A page for every factory seat. Where the factory area is turned on, every seat on a factory's Seats tab opens a
  page of its own: who it is, what it does, how it starts, the factory's goal, and what it has left behind. A seat
  with nothing scheduled reads Talk only, and a factory nothing was ever scheduled for reads TALK ONLY. A schedule
  can be taken off its seat from the page or with `cc-devthrottle schedule unlink`; the schedule itself stays.
- A seat's brief lives on the Gateway. A seat's brief can be read, edited, published and brought back from the seat
  page, with every version kept, and from the command line with `cc-devthrottle factory brief get`, `history`,
  `set`, `publish` and `restore`. Only a person publishes; a session can save a draft. Once a brief is published,
  every talk with that seat and every scheduled run of it starts with that brief and its version, and the version
  given is recorded. A seat with no published brief starts exactly as before.
- The Linux app menu icon. On Linux the Director showed as a blank tile in the dock and the app grid; the icon now
  loads, and an installed Director repairs its menu entry and icon at start-up, so installs made before this
  release get the fix by updating.

### Also in this release
- Speak on Linux no longer fails now and then with "'[' is invalid after a single JSON value", and the microphone
  list no longer comes up empty or forgets the default input.
- Every scheduled run is told by the Gateway to report how it went, without changing the schedule's stored prompt,
  and a run that reports ok honours its schedule's close-itself setting.
- The Factory Manager mark can be set only from the owner's own phone or browser, so `cc-devthrottle factory manager
  set` is removed. A session that lost the mark is told where it went, and `factory name-check` refuses an
  incomplete answer instead of printing zero.
- A factory's boss seat has the role Boss, and the registry refuses a boss with another role word.
- The Director's setup wizard no longer promises a trial.
- Saving the updater's state on Windows no longer fails with access denied when a virus scanner or the indexer has
  the file open.
- The test suites lost the tests whose result depended on the machine - a sleep, the real clock or a real process -
  so a release is decided by the code, not by how busy the machine was.

The remote access plan check, the AI plan check, the Licenses page writes and sign-in approvals, the failed-renewal
email, the seat pages, the seat briefs and the brief given to talks and scheduled runs, the run report instruction
and the Factory Manager rule are in the hosted Gateway. The download carries the Linux app menu icon and its repair,
the Speak fix on Linux, the updater save fix, the setup wizard wording, and the `cc-devthrottle schedule unlink` and
`cc-devthrottle factory brief` commands and the removal of `cc-devthrottle factory manager set`.
