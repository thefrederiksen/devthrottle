## v2.11.0 - September 26, 2026

Every error a new install can hit now reaches us, even before you have signed in, and a prompt sent to a
busy agent is no longer doubled or reported as sent when it was not.

### Highlights
- Install errors reach us before you sign in: when the macOS install script, the setup wizard, the
  launcher or the Director fails on a machine that has not signed in yet, the error is sent to DevThrottle
  instead of staying on the screen or being thrown away. Errors that cannot be sent right away are kept on
  disk and sent later. What is sent is the error, the step, the product version and the operating system,
  with your home folder shortened to `~` and anything that looks like a password or key removed.
- The macOS launcher step says why macOS refused the launcher: the report now carries macOS's own answers -
  whether the file is flagged as downloaded from the internet, its signature, whether the background item
  is switched off, whether the Mac is managed by an organisation, and the security log. A first install also
  clears the "downloaded from the internet" flag from what it places.
- The setup wizard no longer stops silently: an error in the middle of an install is shown on screen with
  Retry, on whichever step you are on, instead of leaving an "Installing..." button that never changes. A
  crash of the wizard, a failed release download and a failed "Launch Director" are reported too.
- A Director that cannot start says so on macOS and Linux, instead of quitting without a word.
- Send Logs to DevThrottle, in the Director's Help menu and the launcher's tray menu, sends the recent log to
  us without a GitHub account and shows a reference to quote.
- Voice and typed prompts are delivered once: every delivery carries its own id, a second copy
  is refused and types nothing, a send to a busy agent answers in time instead of timing out, and a text is
  never reported as sent while it is still sitting in the agent's input.

### Also in this release
- The macOS install script writes a log of every run to `~/Library/Application Support/cc-director/logs/setup/`,
  and each failure report names the step that failed.
- The launcher writes its own log to `logs/launcher/`, where the setup wizard's messages already pointed.
- Short commands the installer runs no longer come back with empty output: on a Mac, the signature check read
  back blank every time.
- Owned sessions no longer get Wingman calls, the Fleet Manager's included, and a stop that arrives just after
  a cancelled judgement is judged instead of lost.
- Bring back in the "A restart is available" window, and File > Restart history, bring the sessions back
  again, and a restored session whose lead is not coming back belongs to you.
- An empty last segment of a CC Recorder recording no longer hides the minutes that did transcribe, and the
  recorder signs in to the hosted Gateway and records at 48 kHz.
- The Cockpit shows each factory's map on its own page.
- cc-secrets no longer crashes listing a value that began with an invisible byte-order mark, and a session can
  run an owner-only cc-secrets command that the owner approved in its chat.
