## v2.35.0-rc1 - November 3, 2026

A test build of the release that moves every DevThrottle update off GitHub and onto devthrottle.com.

### Highlights
- Updates come from devthrottle.com: once this release is installed, the Director, the launcher, the Gateway, the setup wizard and command line, and the tools all look for new releases on devthrottle.com and download every file from there. Nothing reads GitHub to update any more.
- Each release is checked before it is used: the release's file list must match the version devthrottle.com names, and every download is checked against the release's fingerprints, as before.
- A clear message when the download server cannot be reached: an update check that cannot reach devthrottle.com says so and names the address it tried. It never claims you are up to date.
- One-line installers on devthrottle.com: the Mac and Linux install commands are now `curl -fsSL https://devthrottle.com/install-mac.sh | bash` and `curl -fsSL https://devthrottle.com/install-linux.sh | bash`.

### Also in this release
- This is a pre-release for testing on our own machines. Directors on the stable channel do not install it.
