## v2.14.0 - October 4, 2026

The Director asks the Gateway for far less while it sits idle, and links in the terminal are drawn where they
are and open exactly what is written.

### Highlights
- The Director reads the list of sessions at most once every 30 seconds instead of once for every repository. Before,
  the full rescan every five minutes asked the Gateway for the whole list once per repository, so a machine
  with 75 repositories made 75 downloads of about 68 KB each time - about 80 MB an hour from one machine doing
  nothing.
- Skills, workflows and injected text are downloaded only when they have changed. The Director still checks
  once a minute, but the Gateway now answers "not changed" with no body when the Director already holds the
  current copy. The first check after the Director starts is always a full download.
- Links in the terminal are exact. A link on the second or later row of a wrapped line is underlined and
  clickable on the row it is on, not on the row above. An address is no longer cut short at a bracket or an
  apostrophe, and a piece of a path is no longer linked as a drive letter. Rows are joined into one line only
  where the text really wrapped.
- The terminal honours the links a program marks itself. When a program such as Codex sends a link with its
  own address, the terminal uses that address exactly instead of guessing it from the text. When a link's text
  is not its address, hovering shows the full address and it is the first line of the click menu.

### Also in this release
- A file an agent names before writing it becomes a link once it exists: a path found missing is checked
  again after two seconds, the next time the terminal redraws, instead of only after you switch sessions.
- More kinds of path are recognised as links: home-folder paths, network paths, bare file names in the
  repository, and file positions written as ":line 12" or "(42,7)".
- The chat view shows a link as it was written; the detected target is only what opens.
- A failed read of the skill list no longer removes every installed skill. Only a list that is explicitly
  empty removes skills.
- The AI summaries on the Cockpit History page are removed. The page keeps its record of which session came
  from which.
- Narration clips are read from disk when played instead of all being held in the Gateway's memory, and a clip
  at least 14 days old whose session is gone is removed.

The History and narration changes, and the Gateway half of "not changed", are in the hosted Gateway and are
already live there. The download carries the Director half of the two traffic changes, the skill list fix and
all of the link changes.
