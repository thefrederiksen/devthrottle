## v2.35.0 - November 4, 2026

DevThrottle now updates from devthrottle.com. This is the last release your machine fetches from GitHub; every update after it comes from our own download server.

### Highlights
- Updates come from devthrottle.com: once this release is installed, the Director, the launcher, the Gateway, the setup wizard and command line, and the tools all look for new releases on devthrottle.com and download every file from there. Nothing reads GitHub to update any more.
- Each release is checked before it is used: the release's file list must match the version devthrottle.com names, and every download is checked against the release's fingerprints, as before.
- A clear message when the download server cannot be reached: an update check that cannot reach devthrottle.com says so and names the address it tried. It never claims you are up to date.
- One-line installers on devthrottle.com: the Mac and Linux install commands are now `curl -fsSL https://devthrottle.com/install-mac.sh | bash` and `curl -fsSL https://devthrottle.com/install-linux.sh | bash`, and the scripts themselves download from devthrottle.com.

### Also in this release
- Nothing to do on your side: your machine installs this release the usual way, and from then on it updates from devthrottle.com by itself.
- A test install into a folder of its own (`--root`) no longer changes the machine's Start Menu shortcut or PATH.
