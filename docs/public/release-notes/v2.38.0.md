## v2.38.0 - November 7, 2026

A factory start is answered at once, even when it has to wait for a worktree, and a factory run can no longer end without telling you how it went.

### Highlights
- A session start is answered at once: a start that had to wait for a pooled worktree used to hold the Director for up to seven minutes, so the Gateway reported "The Director did not answer within 30 seconds", every other command to that Director waited behind it, and a slow start could even be started twice. The Director now accepts the start straight away, shows the session as starting, and does the wait on its own. If the start fails, the session stays as a failed start carrying the reason in the worktree tool's own words, and a scheduled run whose start failed is recorded as a run that did not run, with that reason.
- A scheduled run reports before it closes: a run that tries to close itself with `cc-devthrottle session done` before reporting is refused, with a sentence naming `cc-devthrottle run result`, which reports and closes in one step. The instruction every scheduled run is given now says plainly that reporting replaces any other way of closing. Runs had been doing their work, closing, and being recorded as "did not report".
- A session refused its factory's journal is told the way in: start the factory's Boss and have it start the seat.
- Licenses warn only when a machine has no ready next license: a license not held on a machine is no longer a problem in itself. A machine at 80% of a limit is fine while it has a next license ready to switch to, and the bar no longer counts a failed renewal of a spare license unless the machine would be stuck without it.
- A failed schedule tells you in Your inbox, never by email, from the factory it belongs to, so you can reply there.
- The Mission button is on the Cockpit and the mobile app, as it already was in the Director.

### Also in this release
- The Director's memory warning banner is gone: the resource meter turning red is the warning.
- The slowness diagnosis is now computed and recorded as the Director runs, and it measures time with a clock that cannot jump.
