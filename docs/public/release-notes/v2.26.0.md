## v2.26.0 - October 20, 2026

This release makes desktop dictation work on a Mac for the first time, and fixes a Settings window that stopped opening after the Director updated itself.

### Highlights
- Dictation on a Mac: the Director records from the Mac's microphone and has what you say transcribed into the prompt box, the same way it already does on Windows and Linux. Until now a Mac could not record at all. The sound that tells you the microphone is listening plays on a Mac too.
- The Mac can finally ask for the microphone: the application could not request microphone access, so macOS never showed a permission prompt and the Director never appeared under System Settings, Privacy and Security, Microphone. It now asks the first time you use Dictate. Because the Mac application is not signed with an Apple developer certificate, macOS may ask again after an update.
- Dictation says so when it heard nothing: a microphone macOS has not granted still records, and records pure silence, which came back as an empty transcript with nothing explaining why. A recording with no sound in it is now refused with a message naming the microphone and where to allow it.
- Settings opens again after an update: updating the Director on a Mac left it running from a folder that no longer existed, and from then on the Settings button did nothing at all, with no message. Settings now opens normally, and a Settings window that cannot be built explains itself rather than doing nothing.

### Also in this release
- The Mac Director installs into the Applications folder, so it has an icon where the Finder and Spotlight look for it. An existing installation moves rather than leaving two icons behind.
- Uninstalling on a Mac removes the background start-up entries the install created.
- Choosing a microphone on a Mac offers the system's current input device; pick the one you want under System Settings, Sound, Input.

Updating the desktop Director installs all of these.
