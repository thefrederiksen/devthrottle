## v2.27.0 - October 20, 2026

This release gives each Director one list of repositories, so a scheduled factory seat can start in any repository the Director has found, not only the ones you added by hand.

### Highlights
- One repository list: the Director used to keep two lists, the repositories it found under the folders it watches and the ones you added with Browse. Every screen showed both, but a factory seat could only start in one you had added by hand, so a repository that was plainly listed was refused. Now everything the Director finds goes into the one list, and Browse adds to the same list. Nothing is ever removed from it by the scan; sorting by last used keeps the ones you work in at the top.
- Factory seats start in found repositories: a seat whose repository the Director found on its own now starts there. If two repositories share a name, the one you added with Browse is used; if that does not settle it, the start is refused and both folders are named. When a repository is not known at all, the message now says so plainly and tells you that browsing to its folder once in the Director adds it.

### Also in this release
- Session rules can now look at the shell commands an agent runs, in a dry run: a rule records what it would have stopped, and nothing is stopped yet.
- The Director can report the desktops it hosts for Factory Boxes. Boxes is switched off for every account and shows nothing until it is turned on.
- Reading a session's terminal output no longer gives up on a busy machine: the check that guards it against runaway input allowed a tenth of a second and now allows a full second.
- Dictation's sound check no longer counts the moment a microphone takes to open as lost audio, so a first recording after a permission prompt is no longer reported as missing words.

Updating the desktop Director installs all of these.
