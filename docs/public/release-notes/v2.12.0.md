## v2.12.0 - September 27, 2026

A session that starts other sessions can now reach them: a waiting session is woken for its messages, and a
session can type into the sessions it owns.

### Highlights
- A waiting session is woken for its messages: the doorbell that tells a session it has messages now rings
  a Claude Code session whose turn has ended, even while a background task or a Monitor keeps "esc to
  interrupt" in its footer. Before, those sessions were never rung, and a coordinator waited for hours on
  sessions that had finished. A session is still never rung over your unsent words or an open menu.
- A sender learns when its message is not getting through: if a message has not been able to ring its
  session for 15 minutes, the sender is told once, with the reason, and the message keeps ringing.
- A session can type into the sessions it owns: a session may send a prompt, or compact and then continue,
  to a session it started and owns. It is typed only when that session is waiting for a prompt and never
  over your unsent words. Every other session is still out of reach, and interrupting a session stays
  yours alone.
- Your Throttle counts only the sessions you started: the voice, phone and surface numbers leave out the
  sessions other sessions and schedules start and drive, and a new "Who runs your sessions" card shows
  how many sessions and turns each kind of starter accounts for. Restored, reopened and handed-over sessions
  keep the starter of the session they continue.

### Also in this release
- Once the Gateway has your spoken words, the Gateway finishes delivering them; the phone stops re-sending
  and reads the outcome instead.
- The Wingman decides most stops without a model call - a menu on the screen, a question in the reply, or a
  wake-up the session set itself - and records which rule decided. A stop with no such sign is judged by a
  model that answers in one word.
- The Wingman writes a short label and the narration for a stop in one step, and the answer buttons are
  gone. When only that write-up fails, the row keeps its colour and plain label instead of showing a
  Wingman error.
- A session that set a wake-up is not turned red before the wake-up is due.
- A stopped session whose screen is redrawn is not read again as a new stop.
- The Fleet Manager page uses the full width and has a Start fresh button that opens a new Fleet Manager
  session and closes the old one.
- The doorbell writes the screen it could not read to the Director log, so a session that is never rung can
  be diagnosed.
- cc-gmail can move one message out of Spam and back into the Inbox (`cc-gmail not-spam`).
