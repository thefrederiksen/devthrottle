## v2.12.0 - September 27, 2026

A session that starts other sessions can now reach them: a waiting session is woken for its messages, and a
session can type into the sessions it owns.

### Highlights
- A waiting session is woken for its messages: the doorbell that tells a session it has messages now rings
  a Claude Code session whose turn has ended, even while "esc to interrupt" stays in its footer. Before, those
  sessions were never rung, and a coordinator waited for hours on sessions that had finished. A session is
  still never rung over your unsent words or an open menu.
- A sender learns when its message is not getting through: if an unread message has not rung once in 15
  minutes, its sender is told once, with the latest reason when one is known, and the doorbell keeps trying.
- A session can type into the sessions it owns: a session may send a prompt, or compact and then continue,
  to a session it directly owns. It is typed only when that session is waiting for a prompt and never over
  your unsent words. Other targets, and interrupting a session, stay yours; what a session you have raised
  may do is unchanged.
- Your Throttle counts only the sessions you started: the voice, phone and surface numbers leave out the
  sessions other sessions and schedules start and drive, and a new "Who runs your sessions" card shows
  how many sessions and turns each kind of starter accounts for. Restored, reopened and handed-over sessions
  keep the starter of the session they continue.

### Also in this release
- Once the Gateway holds your spoken words, or a typed prompt that is still being delivered, the Gateway
  finishes the delivery; the phone and the Cockpit read the outcome and do not send it again.
- The Wingman's answer buttons are gone.
- For accounts that have switched turn judging on (it is off by default): the Wingman first checks four
  signs without a model call - a picker or permission prompt on the screen, the agent's own needs-a-human
  block, a real question in the latest reply, or a way back the session set itself - and records which one
  decided; a stop with none of them is judged by a model that answers in one word. The label and the
  narration are written in one step, and when only that write-up fails the row keeps its colour and plain
  label instead of showing an error. A session whose last turn set a wake-up is not turned red before the
  wake-up is due, and a Claude Code stop whose identity is proven is not judged again only because its screen was redrawn.
- The Fleet Manager page uses the full width and has a Start fresh button that opens a new Fleet Manager
  session and closes the old one.
- When the doorbell cannot read a session's screen, it writes the bottom rows and the cursor to the Director
  log, at most every 30 minutes per session, so a session that is never rung can be diagnosed.
- cc-gmail can move one message out of Spam and back into the Inbox (`cc-gmail not-spam`).
- The voice mode button for all sessions, on the phone and in the Cockpit, now switches on only your own
  sessions and says how many; sessions that another session runs are left alone. Switching off still
  reaches every session.
- Dictation is now requested and recorded as whisper-large-v3, the model that really transcribes it. The
  Director's log and stored transcripts named gpt-4o-transcribe, which the hosted service has not used
  since August 29.
