## v2.33.0 - November 3, 2026

Switching between sessions in the Director is fast again, and git in your worktrees can no longer be left locked.

### Highlights
- Faster session switching: clicking from one session to another no longer waits on git. Each switch used to start a git status and a network fetch for the Source Control page on the screen's own thread, which cost about two seconds per switch even when you were looking at the Terminal tab. The Source Control page now does its git work in the background, and only when you open it.
- No more idle freezes: the Source Control page kept checking git every 15 and 30 seconds all day even while it was hidden. It now checks only while it is on screen.
- No more stuck git locks: the Director's background git checks no longer take git's optional lock, so a check that is cut short can no longer leave an index.lock file behind that made every later commit, pull or checkout in that folder fail with "File exists".

### Also in this release
- Voice sessions recover by themselves after a slow spell at the model host: a narration that came back with no words is now retried automatically instead of staying silent until you press a button.
- A factory Boss can start a seat of its own factory with `cc-devthrottle factory seat start`. The seat runs from the published definition with its full kit, the Boss owns it, and it hands back when finished.
- Every Boss is now told by the Gateway, on every start, that it directs the work rather than doing it, and a scheduled Boss starts only work that can come back before its shift ends.
- The release script no longer stops halfway when git prints a harmless warning, and its download link now points at the right address.
