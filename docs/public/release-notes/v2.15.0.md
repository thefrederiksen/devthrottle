## v2.15.0 - October 5, 2026

You can let two of your sessions talk to each other, and a session that needs to talk to another one can ask you.

### Highlights
- Message links. A session can normally message only the session that started it and the sessions it started.
  You can now let any two of your sessions talk: once, once with a reply, or as much as they need. Set it up from
  a session's menu in the Cockpit ("Let this session talk to..."), or with `cc-devthrottle message link add`. You
  never approve the messages themselves; the two sessions decide what to send. A link for as much as they need
  ends when either session ends or when you remove it.
- A session can ask you for a link. When a message is refused, the session is told how to ask:
  `cc-devthrottle message request <session> "why it needs to talk"`. You see a card at the top of the Sessions
  screen in the Cockpit with who is asking, whom it wants to talk to and its reason, and you answer with One
  message, One message and a reply, As much as they need, or No. The session hears your answer in its inbox.
  A session may have at most three requests waiting, and after a No it may not ask for the same thing again
  for an hour.

### Also in this release
- `cc-devthrottle message link list` and `message link remove` show and end the links you have set up.
- A Fleet Manager session that you have given the right to manage links can list and answer requests with
  `cc-devthrottle message link requests` and `message link answer`.

The links, the requests and the Cockpit screens are in the hosted Gateway and are already live there. The
download carries the `cc-devthrottle message` commands that sessions use to ask, and that you can use from the
command line.
