Factories in the Cockpit: one simple list, and a Talk button on every agent

Factory Manager, 6 October 2026. Version 4: every question answered. The design is settled and carried on devthrottle#3585 for the build.

Summary

The screen, as you decided it: the sidebar says Factories. The list has one row per factory with its name, status and what is waiting on you, and a "Talk to the CEO" button. Each factory's page carries the goal, the goal number the CEO posts on every run, and a Seats tab where every agent has its own Talk button and computer. The top-level "All factory agents" tab is removed.

Talking to an agent: one click opens a top-level session seated as that agent, under the same rules as its scheduled runs. Before it ends, it writes a line in the factory's activity record and puts what you decided into the factory's memory, so the next night's run starts from it.

And in a talk, anything about the factory can change, the goal included. Your words: "the CEO and the user when they talk can strategize on anything that needs to be changed, because now the CEO can get user approval." The goal stays the one file a CEO cannot change on its own; in a talk you are there to approve it, and the change is recorded in GOAL.md with the date and the talk it was agreed in. WarmForward's GOAL.md now says this.

Decisions

No questions - nothing needed from you on this screen. Your answers: row = name, status and waiting on you; seats = a tab in each factory; goal number = posted by the CEO; a talk follows the agent's own rules; a talk leaves an activity line and a memory note; in a talk the goal and the factory's structure may change with your approval.

What pressing Talk does

  1. Opens a new top-level session: you own it, it shows in Sessions, and it is never a child of the Floor Manager or any other session.
  2. On the agent's computer (from the Computer column), in its factory's folder, so the factory's rules load.
  3. Seated as that agent: it starts with the agent's brief, the factory's goal, its memory, and its last runs and reports. The first thing it says is what happened since you last talked and what it needs from you.
  4. Named to the fleet convention: WarmForward - Nora Hale - morning talk with the owner.
  5. What it may do, and what it leaves behind, are the two questions above.
