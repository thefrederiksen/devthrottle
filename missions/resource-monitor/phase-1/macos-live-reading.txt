               memory stalled percent      null - not offered on macOS

               hard page faults a second   null - not offered on macOS
               processes waiting on disk   null - not offered on macOS

   Linux publishes, in /proc/pressure, the share of time programs spent frozen waiting on each
   resource. macOS publishes nothing equivalent, so those four figures are NULL and not zero:
   zero would read as "nothing was ever stalled", which is the opposite of "we cannot tell".
