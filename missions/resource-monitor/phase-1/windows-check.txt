WHAT THIS DOES NOT PROVE
- The mission's 5-point agreement is for the toolbar meter (phase 2); this proves the readings the
  meter will show.
- Measured cost varies with how busy the machine is: 12.5 to 53 ms of processor time per sample was
  seen across runs. Almost all of it is the one kernel call that lists every process and thread
  (about 800 processes and 12,400 threads here; 9 to 18 ms on its own). The sampler's whole budget,
  under 0.5% of one core, is measured in phase 2; if it is over, the lever is how often the process
  list is read, not this code.
- No spinning hard drive is attached to this machine. The spinning case is proved from the real
  solid-state bytes with the one flag a hard drive sets, not from a hard drive.
- The per-processor figures cover one processor group: every processor on a machine with 64 or
  fewer. The whole-machine figure covers all of them regardless.
- Processes' disk bytes on Windows are every read and write the process makes (files, devices,
  network, cache hits), because Windows keeps no per-process count of physical disk bytes.
